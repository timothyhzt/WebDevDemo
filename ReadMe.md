# University College Web Experience

A mobile-first university website prototype created to demonstrate
responsive web development, accessibility, UX, and interactive
front-end development.

This is a fictional university website created as a front-end development and UX demonstration. All content is illustrative. It is Not affiliated with or endorsed by Arizona State University.

## Technologies
- HTML
- CSS
- JavaScript
- Git

## Focus
- Mobile-first design
- Accessibility
- Responsive layouts
- UX
- Interactive components
- Performance

## Features
- Basic Questionaire/what you want a day in your life to look like/ types of life
- Options- types of majors
- Clubs/Organizations
